# Análise de Faturamento Acumulado por Categoria (SQL)
Repositório contendo a resolução de um desafio de banco de dados aplicado aos setores de Finanças, Controladoria e Business Intelligence (BI). O projeto foca no uso de Funções de Janela agregadas para calcular o efeito acumulado de receitas ao longo do tempo.

#Descrição do Desafio
O objetivo do projeto é estruturar um pipeline de faturamento que calcule a evolução das vendas diárias. A regra de negócio exige que esse cálculo de efeito "bola de neve" financeira seja segmentado e isolado de forma totalmente independente para cada categoria de produto do catálogo, garantindo que o saldo de uma operação não interfira na outra.

UTILIZEI: SQL, SUM(), OVER(), PARTITION BY, ORDER BY ASC
